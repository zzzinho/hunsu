# hunsu

HTML 로 디자인하는 로컬 디자인 도구. 브라우저에서 HTML 원본을 직접 고치거나, LLM 에게 말로 페이지를 만들고 고치게 한다.

![hunsu 시연: 렌더 화면에서 제목을 선택하고 "이 제목을 호박색으로 바꾸고 더 크게" 라고 요청한 뒤, 모바일 너비로 확인하고 되돌린다](docs/demo.gif)

시연(20초): 구성 요소 선택 → 말로 수정(진행 상황 표시, 기다리는 구간은 3배속) → 모바일 너비로 확인 → 되돌리기. 모델은 haiku.

- **말로 만들고 고치기**: 빈 폴더에서 "카페 랜딩 페이지 만들어줘" 로 페이지와 디자인 시스템을 한 번에 만들고, 이어서 "이 버튼 더 크게" 처럼 고친다.
- **구성 요소 선택**: 렌더 화면에서 요소를 클릭해 "이거" 를 지정한다.
- **외부 에이전트 연결 (MCP)**: Claude Code, Codex 같은 MCP 클라이언트가 브라우저에서 선택한 요소를 알고 직접 고친다. 결과는 브라우저에 바로 보인다.
- **디자인 시스템**: 모든 페이지가 공유하는 디자인 규칙(`DESIGN.md`)과 값(`design.css`)을 두고, 사람과 LLM 이 같이 따른다.
- **원본 직접 편집**: 소스 에디터에서 고쳐 저장하면 렌더 화면에 바로 반영된다.
- **되돌리기**: LLM 요청 하나를 통째로 되돌린다.
- **LLM 교체 가능**: 브라우저 채팅의 LLM 은 provider 인터페이스 뒤에 있다. 지금(PoC)은 Claude Code CLI 를 쓴다.

## 요구 사항

| 항목 | 용도 |
|---|---|
| macOS | 실행 환경 |
| [Claude Code](https://claude.com/claude-code) CLI (`claude`), 로그인된 상태 | 브라우저 채팅의 LLM provider (PoC). 구독 로그인과 API 키 모두 된다. |
| Go 1.27 이상 | 빌드할 때만 필요하다 |

## 빌드와 실행

```bash
go build -o hunsu .
./hunsu ~/designs      # 디자인 폴더. 생략하면 현재 디렉터리
```

서버가 `http://127.0.0.1:7777` 에 뜨고 기본 브라우저가 열린다. 포트는 MCP 클라이언트에 등록한 주소가 바뀌지 않도록 고정이고, 바꾸려면 `-port 8888`. 브라우저를 자동으로 열지 않으려면 `-no-open`. 끝내려면 터미널에서 Ctrl+C.

## 화면 구성

![hunsu 화면: 왼쪽 파일 패널, 가운데 75% 로 축소한 모바일 렌더 영역에서 제목이 선택된 상태, 오른쪽 소스 에디터와 채팅](docs/screenshot.png)

| 패널 | 내용 |
|---|---|
| 파일 패널 (왼쪽) | 디자인 시스템 파일, 페이지 목록, 새 페이지 추가 |
| 렌더 영역 (가운데) | 렌더된 페이지. 위쪽 막대에 패널 접기, 선택·손 도구, 모바일/데스크톱 너비, 확대/축소 |
| 편집기·채팅 패널 (오른쪽) | 위는 소스 에디터, 아래는 채팅 |

- 패널 경계를 끌어 크기를 바꾼다. 더블클릭하면 기본 크기로 돌아간다.
- 막대 양 끝의 버튼으로 파일 패널, 편집기·채팅 패널을 접고 편다. 네 모서리 버튼은 렌더 영역만 남긴다.
- 패널 크기, 접힘, 배율은 브라우저에 기억된다.

## 사용법

### 채팅으로 만들고 고치기

채팅 입력창에 요청을 쓰고 Enter (줄바꿈은 Shift+Enter).

- 빈 프로젝트에서 "카페 소개 랜딩 페이지 만들어줘" → 페이지와 디자인 시스템을 만들고 자동으로 연다.
- "메뉴 페이지(menu.html)도 같은 디자인으로 만들어줘" → 새 페이지를 만들고 연다.
- "모든 페이지의 버튼을 더 둥글게" → 여러 페이지를 함께 고친다.
- 진행 상황이 "index.html 쓰는 중 · 12.4KB · 23초" 처럼 보인다. 실행 중에는 [보내기] 가 [취소] 로 바뀐다.
- 대화는 프로젝트마다 이어진다 ("아까 그 버튼 되돌려"). 서버를 다시 켜도 이어지고, [새 대화] 로 처음부터 시작한다.
- [되돌리기] 는 마지막 요청 직전 상태로 프로젝트를 돌린다. 새로 생긴 페이지는 지운다. 여러 번 누르면 더 이전으로 간다.
- 모델 목록과 기본 모델은 provider 가 정한다. 지금의 Claude Code provider 는 opus 가 기본이고 sonnet, haiku 로 바꿀 수 있다 (사용자의 claude 기본 모델 설정과 관계없다). 새 페이지를 통째로 만들 때 opus 는 약 1분 40초, haiku 는 약 30초 걸린다.

### 구성 요소를 골라서 고치기

1. 렌더 영역 막대에서 선택 도구(↖, V)를 고른다. 기본값이다.
2. 마우스를 올리면 외곽선이 생기고, 클릭하면 입력창 위에 "선택 `main > button.cta` ×" 칩이 붙는다.
3. "이거 배경 빨간색으로" 처럼 요청한다. LLM 은 "이거" 를 선택한 요소로 이해한다.

LLM 이 페이지를 고쳐도 같은 요소를 다시 찾아 선택을 유지한다. Esc 나 칩의 × 로 해제한다.

### 렌더 영역 도구

| 도구 | 동작 |
|---|---|
| 선택 (↖, V) | 클릭으로 구성 요소를 고른다. 페이지의 링크·버튼은 동작하지 않는다. |
| 손 (✋, H) | 끌어서 페이지 안을 이동한다. 끌지 않고 누르면 링크·버튼이 그대로 동작한다. |
| 모바일 / 데스크톱 | 390px 화면 / 렌더 영역 전체 너비 |
| − 100% + | 25%~300% 확대/축소. 퍼센트를 누르면 100% |

### 디자인 시스템

프로젝트 루트의 두 파일이 모든 페이지가 공유하는 디자인 규칙이다. 파일 패널 맨 위에 있고, 없으면 클릭해서 템플릿으로 만든다.

| 파일 | 내용 |
|---|---|
| `design.css` | 색·간격·모서리·폰트 CSS 변수와 공통 클래스. 모든 페이지가 링크하므로 값을 바꾸면 모든 페이지에 바로 반영된다. |
| `DESIGN.md` | "버튼은 primary 배경에 흰 글씨" 처럼 글로 쓴 규칙. LLM 이 따른다. |

두 파일의 내용은 요청마다 LLM 에게 함께 전달된다. 대화 도중에 바꿔도 다음 요청부터 반영된다.

### 직접 편집

파일 패널에서 파일을 열고 소스 에디터에서 고친 뒤 ⌘S 나 [저장]. 렌더 영역이 바로 바뀐다. VS Code 같은 다른 에디터로 고쳐도 0.5초 안에 반영된다. 직접 고친 파일은 다음 요청 때 LLM 에게 알려 준다.

### 외부 에이전트에서 작업하기 (MCP)

브라우저 채팅 대신 Claude Code, Codex 같은 에이전트로 작업할 수 있다. 에이전트의 설정·스킬·긴 대화를 그대로 쓰면서, 브라우저에서 선택한 요소를 "이거" 로 가리키고 결과를 바로 본다. hunsu 는 표준 MCP(Streamable HTTP)로 열려 있어서 특정 클라이언트에 묶이지 않는다.

1. hunsu 를 실행하면 터미널에 MCP 주소와 토큰이 나온다.

   ```
   MCP 서버: http://127.0.0.1:7777/mcp (헤더 Authorization: Bearer <토큰>)
   ```

2. 쓰는 MCP 클라이언트에 이 주소와 헤더를 HTTP(Streamable HTTP) 서버로 한 번 등록한다. Claude Code 라면:

   ```bash
   claude mcp add --transport http -s user hunsu http://127.0.0.1:7777/mcp -H "Authorization: Bearer <토큰>"
   ```

   다른 클라이언트도 같은 주소와 헤더로 등록한다.

3. 디자인 폴더에서 에이전트를 실행하고 요청한다. 예: "hunsu 에서 내가 선택한 요소 글자색을 빨간색으로 바꾸고, about 페이지를 같은 디자인으로 만들어서 열어줘"

에이전트는 아래 도구로 hunsu 와 주고받고, 파일은 자기 파일 편집 도구로 직접 고친다. hunsu 는 저장되는 즉시 브라우저에 다시 그린다.

| 도구 | 동작 |
|---|---|
| `get_context` | 디자인 폴더 경로, 페이지 목록, 디자인 시스템 내용, 브라우저에 보이는 페이지, 선택한 요소 |
| `checkpoint` | 고치기 전 상태 저장. 브라우저의 [되돌리기] 로 에이전트의 수정도 되돌릴 수 있다 |
| `undo` | 마지막 checkpoint 로 되돌리기 |
| `open_page` | 브라우저에 페이지 열기 |

- 토큰은 처음 실행할 때 `~/Library/Application Support/hunsu/mcp-token` 에 만들어지고(본인만 읽기 가능), 다음부터 같은 토큰을 쓴다. 토큰이 없거나 틀리면 `/mcp` 는 거부한다.
- 디자인 규칙은 브라우저 채팅과 같은 것을 MCP 안내문으로 에이전트에 전달한다.
- 에이전트를 디자인 폴더가 아닌 곳에서 실행하면 파일을 고칠 때마다 권한 확인을 받을 수 있다.

## 단축키

| 키 | 동작 |
|---|---|
| V / H | 선택 도구 / 손 도구 |
| Esc | 선택 해제 |
| ⌘+ / ⌘− / ⌘0 | 확대 / 축소 / 100% |
| 핀치, Ctrl+휠 | 확대/축소 |
| ⌘\\ | 렌더 영역만 보기 |
| ⌘S | 저장 |
| Enter / Shift+Enter | 요청 보내기 / 줄바꿈 |

V, H, Esc 는 입력창이나 에디터에 글을 쓰는 중에는 동작하지 않는다.

## 디자인 폴더 구조

```
designs/
  DESIGN.md        # 디자인 규칙 (글)
  design.css       # 디자인 규칙 (CSS 변수, 공통 클래스)
  index.html       # 페이지. 루트 폴더의 .html 만 페이지로 다룬다
  menu.html
  .hunsu/          # hunsu 가 관리한다
    session        # 이어지는 LLM 대화의 ID (provider 가 정한다)
    history/       # 요청 직전 스냅샷 (되돌리기용)
```

페이지는 CSS·JS 를 안에 직접 쓰고, 외부 파일은 `design.css` 만 링크한다.

## LLM provider

브라우저 채팅의 LLM 은 `llm.Provider` 인터페이스(`internal/llm`) 뒤에 있다. 핵심 코드는 이 계약만 알고, provider 는 `main.go` 한 곳에서 고른다. Anthropic API, Codex 같은 다른 LLM 은 이 인터페이스를 구현해 추가한다 (방법은 [`PLAN.md`](PLAN.md) 18).

지금(PoC)의 provider 는 Claude Code CLI(`internal/claude`)다. 요청마다 `claude -p` 를 디자인 폴더에서 실행한다.

- 사용자의 개인 설정(CLAUDE.md, hook, 플러그인, MCP 서버)을 불러오지 않는다. 디자인 편집에 섞이지 않고, 격리하지 않을 때보다 2배 빠르고 10배 싸다.
- 파일 읽기·쓰기 도구만 쓰고, 명령 실행은 하지 않으며, 디자인 폴더 밖의 파일에는 접근하지 못한다.
- 비용은 사용자의 Claude 계정에서 나간다. 작은 수정은 haiku 로 1센트 미만, opus 로 새 페이지를 만들면 약 $0.3 이다 (측정값, `PLAN.md` 14·16).

## 개발

```bash
go test ./...          # Go 테스트
node --test web/       # 프론트엔드 판단 로직 테스트
go build -o hunsu .
```

| 경로 | 책임 |
|---|---|
| `main.go` | 조립 지점: 실행 인자, LLM provider 선택, 서버 시작, 브라우저 열기 |
| `internal/project` | 디자인 폴더 접근. 편집 대상 판단, 폴더 밖 접근 차단 (`os.Root`), 템플릿, 공용 디자인 규칙 |
| `internal/watch` | 파일 변경 감지 (폴링) |
| `internal/llm` | LLM provider 계약: 요청, 진행 이벤트, 모델 목록. 핵심 패키지는 이것만 안다 |
| `internal/claude` | PoC provider: `claude -p` 인자, 진행 이벤트 해석, 프로세스 실행·취소, 모델 목록 |
| `internal/history` | 요청 직전 스냅샷과 되돌리기 |
| `internal/chat` | 요청 하나의 처리: 동시 실행 막기, 프롬프트·디자인 시스템 조립, 대화 이어가기 |
| `internal/server` | 브라우저용 HTTP API 와 스트림 |
| `internal/ui` | 브라우저가 알린 화면 상태(보는 페이지, 선택한 요소)와 브라우저로 보내는 명령 |
| `internal/mcp` | MCP 서버 (Streamable HTTP, 도구 호출만), 토큰 인증 |
| `internal/mcptools` | hunsu 의 MCP 도구와 에이전트용 안내문 |
| `web/` | 브라우저 UI. 빌드 단계 없는 JS 모듈. `*.mjs` 의 판단 로직은 `*.test.mjs` 로 테스트한다 |

- 외부 의존성은 없다. Go 는 표준 라이브러리만, 프론트엔드는 CodeMirror 5 파일만 포함한다.
- 코드 규칙(SRP·OCP·TDD, 테이블 테스트)은 [`CLAUDE.md`](CLAUDE.md), 설계 결정과 측정값은 [`PLAN.md`](PLAN.md) 에 있다.

## 알려진 한계

- **localhost 보호 일부만 적용**: `/mcp` 는 토큰, 화면 상태 API 는 출처 검사로 막았지만, 나머지 브라우저용 API 는 아직 검사가 없다. 다른 웹사이트가 hunsu 의 포트를 알아내면 디자인 파일을 고칠 수 있다. 다음 마일스톤에서 막는다.
- LLM provider 는 아직 Claude Code CLI 하나뿐이다.
- 에이전트가 `open_page` 없이 새 페이지를 만들면 브라우저의 파일 목록은 다음 조작 때 갱신된다.
- macOS 만 확인했다.
- 페이지는 디자인 폴더 루트의 `.html` 만 다룬다. 하위 폴더와 이미지 같은 파일은 다루지 않는다.
- 페이지 JS 가 실행 중에 붙인 클래스·id 는 선택 경로에 들어가지만 파일에는 없어서, LLM 이 그 경로로 고치면 적용되지 않을 수 있다.
- 되돌리기 스냅샷은 쌓이기만 하고 정리되지 않는다.
